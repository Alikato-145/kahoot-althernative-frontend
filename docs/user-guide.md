# คู่มือการใช้งาน Camp Quiz

## สำหรับ Host

1. เปิด `/host` แล้วเลือก **สร้าง Quiz ใหม่** หรือกด **ทำสำเนา** เพื่อคัดลอก Quiz เดิมที่มี session อยู่
2. ใส่ชื่อและคำอธิบาย Quiz กำหนดเวลา Intro, ตอบคำถาม และเฉลย (ใช้กับทุกข้อในห้องนั้น)
3. แต่ละคำถามต้องมีตัวเลือก 4 ตัวเลือก และเลือกคำตอบที่ถูกต้อง 1 ตัวเลือก
4. อัปโหลดรูปคำถามและรูปเฉลยได้จากเครื่อง พร้อมใส่คำอธิบายเฉลย แล้วกดบันทึก
5. กด **เริ่มเกม** เปิดหน้าห้องบนจอโปรเจกเตอร์ และให้ผู้เล่นสแกน QR หรือเข้า `/join`
6. กดเริ่มคำถาม รอรับคำตอบ แล้วกด **ปิดรับคำตอบ** และ **เฉลย** ระบบจะแสดงภาพเฉลย คำอธิบาย และอันดับแบบเคลื่อนไหว

> Quiz ที่มี game session แล้วจะไม่สามารถแก้ไขหรือลบได้ เพื่อรักษาข้อมูลผลการแข่งขัน ให้ใช้ **ทำสำเนา** แทน

## สำหรับผู้เล่น

1. เปิด URL เดียวกับ Host บนโทรศัพท์ หรือสแกน QR จากหน้าห้อง
2. ใส่ PIN 6 หลักและชื่อเล่น แล้วกดเข้าร่วม
3. รอ Host เริ่มคำถาม เลือกคำตอบ 1 จาก 4 ช่องภายในเวลาที่กำหนด
4. หลังหมดเวลา ดูผลเฉลย คะแนน และอันดับของตัวเองบนหน้าจอ

## รันแบบพัฒนาในเครื่อง

```sh
cp .env.example .env
docker compose up -d
npm ci
npm run db:migrate
npm run dev
```

เปิด `http://localhost:3000/host` สำหรับ Host และ `http://localhost:3000/join` สำหรับผู้เล่น

## ติดตั้ง bare-metal

ทำตาม [คู่มือ operations](operations.md) ตามลำดับ: ติดตั้ง Node.js 20, MySQL 8, Redis 7, Nginx และ Certbot, ตั้งค่า `/etc/camp-quiz.env`, migrate/build, เปิด systemd service แล้วตั้ง Nginx HTTPS/WSS

อย่าเปิดพอร์ต Node 3000, MySQL 3306 หรือ Redis 6379 สู่ภายนอก ผู้เล่นและจอ Host ต้องใช้ public HTTPS hostname เดียวกัน
